# handwired/pico_redox

![handwired/pico_redox](imgur.com image replace me!)

*A short description of the keyboard/project*

* Keyboard Maintainer: [Anieway](https://github.com/Anieway)
* Hardware Supported: Waveshare RP2040-Tiny, handwired in Redox handwire
* Hardware Availability: [Redox Handwire](https://www.thingiverse.com/thing:2704567), [Waveshare RP2040tiny](https://www.waveshare.com/rp2040-tiny.htm)

Make example for this keyboard (after setting up your build environment):

    make handwired/pico_redox:default

Flashing example for this keyboard:

    make handwired/pico_redox:default:flash

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).

## Bootloader

Enter the bootloader in 3 ways:

* **Bootmagic reset**: Hold down the key at (0,0) in the matrix (usually the top left key or Escape) and plug in the keyboard
* **Physical reset button**: Hold down reset button and plug in keyboard
